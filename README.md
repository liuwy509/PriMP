# PriMP

Cleaned core implementation of PriMP for cross-domain few-shot object detection.

This repository provides the core implementation of PriMP, including:

- semantically enhanced prompt construction;
- offline prototype-bank construction;
- uncertainty-aware adaptive gating;
- prototype-based inference-time calibration;
- example evaluation scripts.

Large pretrained weights and public datasets are not redistributed in this repository. Please download them from their official sources.

The complete training scripts, support splits, prompt files, and prototype files used in the paper will be further organized and released upon acceptance.
